Updated Windows build and Unity source for the existing JOHN WICK NMU project.

- Improved walking, backward motion, aim-walking, turning, grip reach and sprint recovery.
- Harder opponents with faster reactions, strafing, motion leading and headshot attempts.
- Nighttime NMU campus with three branded buses, street details, wet asphalt and lighting.
- Rendered portraits, cleaner HUD/ammo slots, recorded pistol/pain audio and corrected hit effects.
- Preserved coin toss, countdown forfeits, three shots per round, 50/30/10m rounds and opponent progression.

Download the Windows ZIP below, extract the entire folder, and run LAST STEP.exe. Open Settings > Map to select NMU. Controls: WASD, mouse aim, left click fire, right click aim, Shift sprint, Space dodge, Escape pause.

This is a playable development release. Character faces, directional animation and environmental models remain simplified; it does not match the target image's photoreal quality. Executed test/build reports and asset attribution are included in the repository under Documentation. No blanket license is granted for the full project.
